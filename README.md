## Descrição
Uma programa de reservas para alunos do curso de PF (Processos Fotográficos), do IFPR campus Curitiba, do qual os estudantes, tanto técnico quanto subsequente, podem visualizar e reservar horários do laboratório/estúdio de fotos.

<br>

## Funcionalidades
- `Funcionalidade 1` `Cadastro de Alunos`: Nosso sistema precisa estar apto a cadastrar os alunos associados ao curso de Processos Fotográficos. Para cadastrar um aluno, devem ser informados seu e-mail institucional (válido e único dentro do sistema), seu nome e se é aluno do subsequente ou do técnico. Todos os campos são obrigatórios. O sistema também deve gravar a data em que o estudante foi cadastrado no sistema.

- `Funcionalidade 2` `Cadastro de reservas`: O sistema precisa reservar um horário selecionado pelo estudante. Para o cadastro de um horário no sistema, é preciso selecionar a data, e o horário em um intervalo de 1 hora. As informações como nome do estudante e curso devem ser visualizáveis para os demais alunos que desejam reservar horário.
