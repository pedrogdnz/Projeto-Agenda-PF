MODEL
É a representação dos dados estruturada em forma de classe dentro do Flutter. O Service traz o dado bruto (JSON), e o Model transforma isso em um objeto que o Dart entende.

// Transforma o dado bruto (Map/JSON) em um objeto Dart.
class User {
  final String name;

  User({required this.name});

  // O Model é responsável por essa conversão
  factory User.fromJson(Map<String, dynamic> json) {
    return User(name: json['name']);
  }
}
